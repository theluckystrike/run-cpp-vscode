## Input and test cases

1. Open the Input & Tests panel (Run C++ in the bottom panel, or the editor's "..." menu).
2. Type or paste the input, then press Run with input (Ctrl+Enter in the box).
3. You see stdout, stderr, the exit code, the run time and the peak memory.
4. Press Save as test case. The output becomes the expected output; edit it if it is wrong.
5. Run all tests shows pass or fail for each case, with a line diff for each failure.

Test cases are saved in `.zovo-run/tests/` in your workspace, so you can commit them with the code.
